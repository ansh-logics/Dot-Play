# dot(.)music QA audit, 6 Nov 2026

Scope: the desktop app (React and Rust/Tauri), the phone remote and its relay, the menu bar and immersive windows, the website, the install script and CI.

How it was checked: every file was read, the automated checks were run, and each finding was confirmed in the code before anything was changed. The app was not launched, so everything marked **needs an in-app check** still has to be tried by hand.

## Baseline (before any fixes)

Everything passed:
- **Lint:** warnings only.
- **Types:** clean.
- **Tests:** 45 JS tests and 16 Rust tests.
- **Builds:** the app, the phone page, the site and the relay all built.

So the problems below are behaviour bugs and design gaps, not broken builds.

## Not fixed: needs a decision or in-app testing

Ranked by priority:

1. **Content Security Policy is off (`"csp": null`), and every window has every command.** Any script injection, for example through lyrics, titles or remote data, gets full IPC access. That includes `save_session`, which the frontend never calls but which can set arbitrary cookies. To fix:
   - Add a CSP covering self, `127.0.0.1:*`, YouTube and the image hosts.
   - Remove `save_session`.
   - Give the tray and immersive windows smaller capability sets.

   This needs in-app testing because a wrong CSP breaks playback.
2. **Playlists stop at about 100 tracks** (`playlist.rs`). Continuation tokens are never followed, so Liked Music and other big playlists are cut short.
3. **The Google cookie jar is stored in plaintext.** Every `*google.com` cookie goes into `session.json`. Keep only the YouTube cookies the app needs, and move them to Keychain.
4. **The install script trusts any signature.** The app is ad-hoc signed, so `codesign --verify` only proves integrity, not who signed it. Either verify the minisign `.sig` against the updater key (that needs a verifier on the Mac), or sign with a Developer ID. Also pin the GitHub Actions to commit SHAs.
5. **Relay hardening.** Today:
   - Anyone who knows the room id can take up all 8 phone slots (a DoS).
   - A revoked phone still knows the room.
   - There are no per-IP limits, and idle rooms are never cleaned up.

   Proposed: require proof of a room key when joining, rotate the room when a phone is revoked, add a Cloudflare rate-limit rule, and add an alarm that cleans up idle rooms.
6. **Pairing has no forward secrecy.** The QR code plus a capture of relay traffic reveals the device secret. Add an ECDH exchange and a short code shown on both the phone and the Mac.
7. **Lyrics can take up to about 38 seconds.** Up to 12 providers are tried one after another. Racing them under one 6-second deadline would fix it.
8. **Shuffle only applies at the moment it is switched on.** Queues filled later stay in order.
9. **Performance:**
   - Queues and playlists aren't virtualized, which matters at a few thousand songs.
   - `currentTime` re-renders the whole app 10 times a second (a few callbacks need `useCallback`).
10. **Accessibility:**
    - Modals don't move, trap or restore focus.
    - Some `role="button"` elements have no Enter or Space handling.
    - Playlist rows can't be reached by keyboard.
11. **Windows gaps:** no media keys, no idle immersive mode and no F-key shortcut. The UI should hide these on Windows.
12. **Website:**
    - Images are 2000 px JPEGs only; WebP plus `srcset` would cut mobile weight by about 70%.
    - The page has no prerendering.
    - Google Fonts are not self-hosted.
    - There is no robots.txt or sitemap.
    - The import demo makes 18 iTunes calls; bundling the covers would remove them.

## In-app smoke test before tagging
- Play, next and auto-advance. Each should load the video once, with no double buffering blip.
- Play a playlist that contains a blocked song. It should skip with a toast.
- Make a playlist fail to load (go offline), then click Home. The error should clear.
- Right-click a track in an open playlist and press Esc. Only the menu should close.
- Phone Remote: pair, deny, then check that the QR code refreshes. Open the remote in two tabs: no flapping. Restart the Mac app: commands still work.
- Import a pasted list containing "50 Cent - In Da Club".
